Berikut adalah hasil konversi lengkap untuk **Dialog (Modal)** dan **Demo Onboarding Multi-step** ke tech stack target Anda: **Svelte 5 Runes**, **Bits-UI (v2)**, **Tailwind CSS**, **Lucide Svelte**, dan **TypeScript**.

Semua dependensi React (`@radix-ui/react-dialog`, `@radix-ui/react-icons`, `@radix-ui/react-slot`, `class-variance-authority`) digantikan oleh **`bits-ui`**, **`lucide-svelte`**, dan helper `cn` bawaan proyek Anda.

### 2. Demo Komponen: `src/components/demo/OnboardingDialogDemo.svelte`

Menggunakan `$state` untuk manajemen langkah (*step*), `$derived` untuk kondisi tombol, dan snippet Svelte 5 untuk passing trigger ke `Button.svelte`.

```svelte
<script lang="ts">
  import { cn } from "$lib/utils";
  import Button from "$components/ui/button/Button.svelte";
  import {
    Dialog,
    DialogClose,
    DialogContent,
    DialogDescription,
    DialogFooter,
    DialogHeader,
    DialogTitle,
    DialogTrigger,
  } from "$components/ui/dialog";
  import { ArrowRight } from "lucide-svelte";

  const stepContent = [
    {
      title: "Welcome to Origin UI",
      description:
        "Discover a powerful collection of components designed to enhance your development workflow.",
    },
    {
      title: "Customizable Components",
      description:
        "Each component is fully customizable and built with modern web standards in mind.",
    },
    {
      title: "Ready to Start?",
      description:
        "Begin building amazing interfaces with our comprehensive component library.",
    },
    {
      title: "Get Support",
      description:
        "Access our extensive documentation and community resources to make the most of Origin UI.",
    },
  ];

  const totalSteps = stepContent.length;
  let step = $state(1);
  let open = $state(false);

  function handleContinue() {
    if (step < totalSteps) {
      step += 1;
    }
  }

  // Reset step ketika dialog dibuka kembali
  $effect(() => {
    if (open) {
      step = 1;
    }
  });
</script>

<Dialog bind:open>
  <DialogTrigger>
    {#snippet children(props)}
      <Button variant="outline" {...props}>Onboarding</Button>
    {/snippet}
  </DialogTrigger>

  <DialogContent class="gap-0 p-0 [&>button:last-child]:text-white">
    <div class="p-2">
      <img
        class="w-full rounded-lg object-cover"
        src="https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?w=800&auto=format&fit=crop&q=80"
        width={382}
        height={216}
        alt="Onboarding illustration"
      />
    </div>

    <div class="space-y-6 px-6 pb-6 pt-3">
      <DialogHeader>
        <DialogTitle>{stepContent[step - 1].title}</DialogTitle>
        <DialogDescription>{stepContent[step - 1].description}</DialogDescription>
      </DialogHeader>

      <div class="flex flex-col justify-between gap-4 sm:flex-row sm:items-center">
        <!-- Bullet Indicators -->
        <div class="flex justify-center space-x-1.5 max-sm:order-1">
          {#each Array(totalSteps) as _, index}
            <div
              class={cn(
                "h-1.5 w-1.5 rounded-full bg-primary transition-all",
                index + 1 === step ? "bg-primary w-3" : "opacity-20"
              )}
            ></div>
          {/each}
        </div>

        <DialogFooter>
          <DialogClose>
            {#snippet children(props)}
              <Button type="button" variant="ghost" {...props}>Skip</Button>
            {/snippet}
          </DialogClose>

          {#if step < totalSteps}
            <Button class="group" type="button" onclick={handleContinue}>
              Next
              <ArrowRight
                class="-me-1 ms-2 opacity-60 transition-transform group-hover:translate-x-0.5"
                size={16}
                strokeWidth={2}
                aria-hidden="true"
              />
            </Button>
          {:else}
            <DialogClose>
              {#snippet children(props)}
                <Button type="button" {...props}>Okay</Button>
              {/snippet}
            </DialogClose>
          {/if}
        </DialogFooter>
      </div>
    </div>
  </DialogContent>
</Dialog>

```
