## 1. Data Source Inventory & Lineage

| Source | Purpose | Backend Client | Persistence | Freshness | Fallback | Endpoint | Frontend Consumer | Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **PostgreSQL 14+** | Relational transactional master data (Users, Auth, Armadas, Products, Sales, DSS Configs, Sessions) | `pg.Pool` (`src/config/database.js`) | Relational ACID Tables (`users`, `armadas`, `products`, `sales_logs`, `dss_configurations`) | Real-time immediate read/write | N/A (Primary Datastore) | All CRUD REST API Endpoints | All Application Pages | **OPERATIONAL** |
| **PostGIS 3+** | Geospatial boundaries, polygons, coordinate points, and distance calculations | PostGIS SQL Functions (`ST_Covers`, `ST_Contains`, `ST_Buffer`, `ST_DWithin`, `ST_AsGeoJSON`) | Spatial Geometry Tables (`zones`, `protocol_roads`, `pois`, `competitors`, `candidate_selling_locations`) | Spatial Index GIST accelerated real-time | Bounding box spatial fallback | `GET /api/zones`, `GET /api/pois/*`, `GET /api/competitors/*`, `POST /api/lbs/check-in` | `MapOpsPage.jsx`, `ZoneManagementPage.jsx`, `RiderOperationalPage.jsx` | **OPERATIONAL** |
| **Overpass API (OSM)** | Raw OpenStreetMap Point of Interest (POI) data ingestion | Axios HTTP Client (`src/services/poi/OverpassClient.js`) | Ingested to `pois_raw` (JSONB) and deduplicated into `pois` | On-demand trigger (`POST /api/pois/sync-city`) & scheduled background BullMQ worker | Cached `pois_raw` snapshot & existing `pois` records | `POST /api/pois/sync-city`, `GET /api/pois/operational-area` | `PoiManagementPage.jsx`, `MapOpsPage.jsx` | **OPERATIONAL** |
| **Open-Meteo API** | Weather telemetry (temperature, precipitation risk, rain, humidity, weather code) | Axios HTTP Client (`src/services/poi/POIWeatherService.js`) | Ingested to `weathers` table with zone timestamp indexing | Hourly forecast sync & dynamic 15-minute TTL cache | Conservatively degraded dry weather fallback (`weather_code: 0`, `rain: 0.0`) with `DEGRADED` semantic badge | `GET /api/weathers/zone/:zone_id`, `GET /api/weathers/hub` | `SuperAdminDashboardPage.jsx`, `MapOpsPage.jsx`, `DssManagementPage.jsx` | **OPERATIONAL** |
| **Map Tiles (OpenMapTiles / CARTO / OSM)** | Leaflet raster basemap tiles rendering for operational control room | Direct browser HTTPS tile requests with dynamic provider URL resolution | User preference stored in `localStorage` (`mova_map_preferences`) and system defaults in `system_settings` | Real-time tile caching per zoom level via CDN | CARTO Dark Matter / Positron Light fallback | `GET /api/system-settings/map-config` | `LeafletMapCanvas.jsx`, `MapOpsPage.jsx`, `RiderMapPage.jsx`, `SettingsPage.jsx` | **CONFIGURABLE** |
| **Field Competitor Survey** | Competitor coffee cart/stall density recording for C6 criterion | Supervisor field input via REST API (`POST /api/competitors`) | Persisted to `competitors` table with PostGIS geometry points | Persistent until manually removed or re-surveyed | Buffer density score defaults to 1.0 (Low Competition) if zero competitors | `GET /api/competitors/zone/:zone_id`, `GET /api/competitors/score/:zone_id` | `CompetitorManagementPage.jsx`, `DssManagementPage.jsx` | **OPERATIONAL** |
| **Redis 7+** | High-throughput geospatial LBS caching & distributed rate limiting | `ioredis` Client (`src/config/redis.js`) | In-memory key-value with persistence (`dump.rdb`) & GEO sets | Real-time (<5ms) rider GPS beacon telemetry | Direct PostgreSQL query fallback | `GET /api/lbs/live-positions` | `MapOpsPage.jsx`, `RiderOperationalPage.jsx` | **OPERATIONAL** |
| **BullMQ Worker** | Background job scheduler & asynchronous workers (Armada 5-min release, POI sync, notifications) | BullMQ Queue & Worker over Redis connection | Redis job queues (`armada-hold-queue`, `poi-sync-queue`) | Atomic delayed jobs with automatic exponential retry | Synchronous manual database unlock trigger | `/api/cron-management/*`, `/api/sync/*` | `AuditCronPage.jsx`, `SettingsPage.jsx` | **OPERATIONAL** |
