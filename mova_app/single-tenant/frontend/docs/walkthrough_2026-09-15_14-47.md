## 2. Pilot Feature Reference Lock: Map Operations (`/map-ops`)

Halaman `src/pages/superadmin/MapOpsPage.jsx` telah dikunci sebagai **Reference Architecture** dengan kepatuhan 5-Gate:
* **G1 Architecture**: 0 import ke `src/components/ui/`, 100% Native Carbon + Carbon Patterns.
* **G2 Data Integrity**: **Zero Mock Data**. Terkoneksi langsung ke `zoneService.getAll()`, `lbsService.getLiveRiders()`, `poiService.getPois()`, dan `useDashboardRealtime()`.
* **G3 Explicit States**: Menampilkan status operasional riil (`SOCKET CONNECTED`, `OFFLINE TELEMETRY`, `NO_DATA`, `LOADING`, `ERROR`), bukan data tiruan.
* **G4 Theme Parity**: Konsistensi kontras & layer pada Gray 100 (Dark) dan White (Light).
* **G5 Responsive & a11y**: 2x Grid layout (16 col → 8 col → 4 col), 2px focus ring, Tab sequence, dan CSS `prefers-reduced-motion`.

## 3. Wave 1 Checkpoint A: Application Shell & RBAC Guard

Telah diimplementasikan dan diverifikasi dengan zero legacy dependencies:
1. **`Header.jsx`**:
   * Murni menggunakan `@carbon/react` `Header`, `HeaderName`, `HeaderGlobalBar`, `HeaderGlobalAction`, `HeaderMenuButton`.
   * Live clock operasional terisolasi dengan timezone eksplisit `Asia/Jakarta` (WIB).
   * Theme switcher toggle (Dark `g100` / Light `white`).
2. **`Sidebar.jsx`**:
   * Murni menggunakan `@carbon/react` `SideNav`, `SideNavItems`, `SideNavLink`, `SideNavMenu`, `SideNavMenuItem`.
   * Penyaringan menu dinamis berbasis `user.role`.
3. **`AppLayout.jsx`**:
   * Menggunakan Carbon `Content` untuk viewport halaman dengan konsumsi auth & theme state yang terisolasi.
4. **`ProtectedRoute.jsx` & `App.jsx`**:
   * Hard route guard yang memeriksa token JWT dan hak akses peran (`allowedRoles`).
   * Mengalihkan direct URL access yang tidak berwenang ke landing page peran yang aman (`getRoleLandingPath`).
   * *Catatan:* Konfigurasi pembagian hak akses per route di `App.jsx` telah disesuaikan manual oleh user dan siap ditata ulang pada tahapan berikutnya.
